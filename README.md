### Penjelasan:
* **`?demo=true`** di bagian akhir tautan URL berfungsi untuk memicu fitur demo otomatis yang sudah dipasang di semua file Anda (`index.html`, `guru.html`, `kelola-soal.html`, `kelola-siswa.html`, `rekap-nilai.html`, dan `siswa.html`). Dengan parameter ini, halaman akan otomatis mendeteksi mode pratinjau tanpa meminta password guru dan langsung memuat data tiruan (*mock data*) yang aman[cite: 2].
* **`width="100%"`** dan **`height="650px"`** membuat ukuran tampilan iframe menyesuaikan lebar layar blog Anda dengan tinggi sekitar 650 piksel (bisa Anda ubah sesuai kebutuhan).
